# 制作前に希望するデザインを確認する

## 確認の目的と進め方

ユーザーは、枠や表で整理するだけでなく、絵・イラストと視覚的な強弱がある資料を希望している。新規制作・デザイン全体の改訂では、作る前に希望を聞く。ビジネス用途だから堅いデザイン、シンプルだから絵なし、と決めつけない。

まず既知の内容を整理し、不明な項目を少数の質問にまとめる。ユーザーが専門用語を知らなくても答えられる言葉と例を使う。全項目を何度も機械的に質問するのではなく、希望する見た目を左右する未決事項を残さないことを目標にする。

回答を待つ間は元資料の読解・事実確認・内容整理まで行ってよい。レイアウト制作、イラスト生成、本編の書き出しは方向性が決まってから行う。無回答や時間経過を同意と見なさない。

## 確認する項目

| 項目 | 確認する内容・選択肢の例 |
|---|---|
| 用途と読み手 | 商談、社内報告、役員会、研修、イベント。誰に何を判断・行動してほしいか |
| 見せ方 | 投影して話す資料、単独で読んでもらう資料、印刷・メール配布。形式・枚数の希望 |
| 雰囲気 | ポップで親しみやすい、端正なビジネス、上品で高級感、先進的で大胆。「ビジネス向けだが柔らかい」などの組み合わせも可 |
| 参考と避けたい表現 | 好きな資料やサイト、そのどこを参考にするか。堅すぎる、子どもっぽい、地味、派手など避けたい印象 |
| 色と文字 | ブランドカラー、明るい／暗い背景、文字の雰囲気、ロゴや指定フォントの有無。細かな色コードは必須にしない |
| 絵・写真の方向性 | フラットイラスト、手描き、立体イラスト、人物・現場写真など。多め／要所／控えめ。AI生成画像を使ってよいか |
| 密度と抑揚 | 大きな絵と短い言葉で見せるか、説明をしっかり載せるか。強く見せたい主張・数字・ページ |
| 制約 | 使用必須素材、編集性、画像の利用条件、使ってはいけない表現 |

既に答えがある項目は再質問せずブリーフへ反映する。「全部お任せ」「参考資料と同じで」などの明示回答があれば、その委任範囲の推奨案を示して進める。既存デザインで合意済みの局所修正も再ヒアリングを要求しない。

## 最初の質問の組み立て例

必要な項目を、例えば次の3つに分けて聞く。回答済みの項目は削除する。

1. どなたに、どの場面で見せる資料ですか。投影用か配布用か、枚数の希望も教えてください。
2. 希望する雰囲気は、ポップで親しみやすい／端正なビジネス／高級感／先進的など、どれに近いですか。参考や避けたい印象、色の希望はありますか。
3. 絵や写真の画風・量、情報量、特に強調したい内容に希望はありますか。AI生成イラストの使用可否や必須素材も教えてください。

選択式ツールを使うときは、異なる軸を無理に1つの選択肢へまとめない。必要なら段階を分けて聞く。ファイル添付が必要な場合は添付を扱える会話経路を使う。

## デザインブリーフとして合意する

回答から、用途／読み手、雰囲気、色・文字、画風・画像量、密度、強調箇所、制約を短くまとめてユーザーへ示す。ユーザーの回答が具体的で矛盾がなければ、その内容を採用すると伝えて制作に進める。重要な希望が未回答・矛盾している場合だけ、そこを追加確認する。

「デザインのイメージをすべて聞く」は、好みの決定を無断で代行しないこと。余白を何ピクセルにするかなど通常の実装判断まで質問し続けることではない。

## 絵・イラストを取り入れる

- 合意した画風で、概念・課題の場面・支援する様子を伝えるイラストを配置する。表紙や転換点には大きな絵を使い、本文ページでは説明に寄り添う絵を使う。
- 人物・実際の製品・現場の証拠を示すなら写真やスクリーンショットを選ぶ。生成イラストを実際の導入事例や人物写真として見せない。
- 画風、線幅、色調、人物の描き方を揃える。無関係なストック素材や絵文字を空きスペースへ散らさない。
- 必要な画像素材がなければ、利用可能な画像生成・検索機能とそのガイドに従う。希望する画像が用意できない場合は、黙って文字と箱だけに戻さず代案を相談する。
- 背景・絵に文字を埋め込むより、見出しや重要な数字を独立した編集可能なテキストとして重ねる。図表の編集性も維持する。

## 強調とページ間の抑揚

統一感は色・文字・画風で保ち、レイアウトは内容に応じて変える。

- 表紙：大きなタイトルと主役となるビジュアルで雰囲気をつくる。
- 課題：読み手が想像できる場面の絵と、短い問題提起を合わせる。
- 解決策：関係図や仕組みの図を主役にする。
- 比較・条件：表を読みやすくし、絵を増やして競合させない。
- 重要な価値や価格：1つの主張・数値を大きく見せ、補足を従属させる。
- 締め：次の行動を強く見せ、連絡先と関連素材をまとめる。

この例を固定のページ構成にはしない。同じ2列カード、同じ帯、同じ大きさの文字を連続させず、情報量の多いページと余白のあるページにリズムをつける。強調は色だけでなく文字サイズ、太さ、面積、配置で表現する。アニメーションを抑揚の必須条件にしない。

## 納品前の確認

希望された雰囲気になっているか、絵が内容を伝えているか、主役が一目で分かるか、全ページが同じ構図になっていないかを確認する。文字・図表・写真の読みやすさと事実性を犠牲にしていないかも確認する。見た目だけでなく、ヒアリングで合意した希望への一致を評価する。
